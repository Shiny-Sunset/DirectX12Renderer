# 仕様（プレイヤー・味方・敵・ステージ）

> **数値の唯一の置き場所は `GameConfig.h`。**ここには意図と調整の範囲を書く。
> 書き写すと必ず食い違うので、`= 5.0f` のような確定値をここに並べない。
> `（案）` はこちらからの提案。採否を決めて `→ 採用 / 却下` を書き足す。

## ★ 先に決めること

Phase 1 のコードの形が変わるものだけ。

### ① 召喚制限の形

| | 結果 | |
|---|---|---|
| **同時出撃数の上限＋クールダウン** | 報酬で上限を上げる | **→ 採用** |
| コストが時間で回復 | 撃ち続けられる | 却下 |
| ステージ全体の累計回数 | **出し渋って操作が減る。狙いと逆** | 却下 |

### ★ 上限に達したときに何ができるか（未決）

味方は死にすぎない設計なので、**上限いっぱいで全員生きている時間が長い。**
そのとき召喚ができないと、**マウスが完全に止まる。**

| | | |
|---|---|---|
| （案）**呼び戻し** | プレイヤーの周囲の味方を手元に戻し、投げ直せる。ピクミンの笛 | |
| 既存の味方を消して置き直す | 1 体ずつ消すのか、まとめてか | |
| 何もできない | **手が止まる。採らないほうがいい** | |

→召喚する味方を選んでない時は、マウスホイールで味方を選ぶ円上の範囲の拡大縮小を行い、右クリックでフリックして味方を誘導させたい。

**→ 決定：**

### ② 味方の攻撃方法

| | | |
|---|---|---|
| （案）**取り付いて継続ダメージ** | **味方がその場に留まるので戦線が見える。**敵に運ばれていく絵も作れる | |
| 近づいて単発攻撃 | 殴って離れるので、どこが戦っているか分かりにくい | |
| 遠距離 | 死ににくいが、置いた位置から動かないので置き直しの判断が要らなくなる | |

→基本的には近距離だけど、種類によっては遠距離攻撃などで近づきすぎない種類も増やしたい。

**→ 決定：**

### ③ ヘイトの決め方

プレイヤーの重みを大きくし、**たまに味方を狙う。**完全にプレイヤー固定だと、味方が安全地帯になって緊張が消える。

| 決めること | |
|---|---|
| 抽選の方法 | （案）対象ごとに重みを付けて抽選。プレイヤーの重みを大きく |
| 切り替えの間隔 | 毎フレーム抽選すると標的がぶれる。（案）一定時間は同じ標的を追う |
| 攻撃されたときの反応 | DANGO DEFENSE と同じく、攻撃された相手のヘイトを一時的に上げるか |

→例えば薙ぎ払いなどの広範囲攻撃を入れて、プレイヤーだけでなく周りの味方を巻き込んで攻撃をしたらいいかも
**→ 決定：**

### ④ 乱数のシード

```cpp
// ローグライクは報酬抽選に乱数を使う。シードを固定できないとバグが再現できない
Game::Game(uint32_t seed);
```

## プレイヤー

| 決めること | 意図・案 | 決定 |
|---|---|---|
| 移動速度 | **敵を釣って歩く**のが仕事なので、敵より少し速い必要がある | |
| 自動攻撃 | 範囲・間隔・威力。（案）**弱い。**倒すのは味方の仕事 | |
| 体力・被弾 | 即死か体力制か。（案）体力制＋無敵時間（DANGO DEFENSE と同じ） | |
| 強化の軸 | 移動速度、体力、召喚のクールダウン、同時出撃数 | |

## 味方

| 決めること | 意図・案 | 決定 |
|---|---|---|
| **同時出撃数の上限** | （案）10〜20 体。**報酬で増やす。**20 体を超えると画面が渾然一体になる | |
| 体力 | **低め。**使い捨てではない。種類ごとに違い、報酬で上がる。Phase 1 は 1 種なので、ここが唯一の調整つまみ | |
| 攻撃方法 | → ★ ② | |
| 攻撃力・攻撃間隔 | | |
| 移動速度 | プレイヤーに付いてくるのか、召喚地点から敵へ直行か | |
| 索敵範囲 | 近くの敵に向かうか、画面内の最も近い敵か | |
| 寿命 | （案）無し。**死ぬことが寿命の代わり**になっている | |
| 召喚のクールダウン | 短いほど忙しい。長いと置き場所をよく考える | |
| **召喚位置の制限** | プレイヤーから一定距離以内か、画面内ならどこでも可か。**制限があると「釣る」に意味が出る** | |
| 種類（Phase 3） | 色で区別。1 モデルの色違いで足りる（ピクミンと同じ） | |

## 敵

| 決めること | 意図・案 | 決定 |
|---|---|---|
| 1 ステージの数 | 画面に収まる範囲。（案）Phase 1 は 5〜10 体 | |
| 体力・攻撃力 | | |
| 移動速度 | プレイヤーより遅い（釣れる必要がある） | |
| **攻撃の形** | パンチなどの近距離攻撃に加えて薙ぎ払いや、衝撃波、魔法による弾幕などの広範囲攻撃も入れたい | |
| 攻撃の予兆 | **当たる前に分かること。**「見えなかった」で死ぬと続かない | |
| 種類（Phase 3） | 攻撃の形で差を付ける | |
| ボス（Phase 3） | 攻撃パターンを複数持つ 1 体 | |

## ステージ

| 決めること | 意図・案 | 決定 |
|---|---|---|
| 寸法 | **画面に収まること**が条件。カメラの画角から逆算する | |
| カメラの角度・高さ | 固定。（案）斜め見下ろし。味方と敵が重なって見えない角度 | |
| 障害物 | （案）Phase 1 は無し。**味方の経路探索が必要になる** | |
| クリア条件 | （案）画面上の敵を全部倒す | |
